Suppression des données

Cette page explique comment supprimer vos données NufiSend et comment suivre une demande de suppression transmise par Meta (Facebook / WhatsApp Business). Nous traitons les demandes dans un délai de {{ responseDelay }} jours.

Vous avez un compte {{ info.serviceName }}

Téléchargez d'abord vos données, puis supprimez définitivement votre compte depuis Paramètres > Confidentialité & données. La suppression est immédiate et sécurisée.

Gérer mes données
Vous avez utilisé Facebook ou Meta

Si vous avez connecté un compte WhatsApp Business avec Facebook, Meta peut nous transmettre une demande de suppression. Utilisez le code de confirmation affiché par Meta pour suivre son traitement.

Ce qui est supprimé

Compte, profil, annuaire, groupes, modèles, programmations, contenus des messages, clés API, jetons et identifiants WhatsApp Business. Les écritures comptables (paiements et mouvements du portefeuille) sont conservées pour satisfaire nos obligations légales, sans donnée permettant de vous identifier.

Vous n'avez pas de compte {{ info.serviceName }}

Si vous recevez des messages d'un expéditeur utilisant {{ info.serviceName }}, répondez STOP au message ou utilisez la page Exercer mes droits. Nous transmettons votre demande à l'expéditeur et pouvons suspendre les envois abusifs.
